# Performance Marketing Dashboard

A single, "app-like" Excel workbook that replaces scattered spreadsheets with
one polished task tracker + campaign dashboard for a performance marketing
role. No dynamic arrays, no add-ins — built to run on Excel 2016/2019 using
legacy-safe formulas (`INDEX`/`MATCH`, `SUMIFS`/`COUNTIFS`, `SMALL`/`LARGE`)
plus real Excel Tables, with VBA layered on top only where formulas
genuinely can't do the job (buttons, popups, cross-sheet automation).

## What's in it

14 sheets, all interconnected: **Dashboard**, **Tasks**, **Archive**,
**Calendar**, **Campaigns**, **Campaigns Archive**, **Monthly Media Plan**,
**Recurring Tasks**, **Schedule** + **Schedule Data**, **Login Information**,
**Quick Links**, **Instructions**, plus an internal-only **Time Log** sheet
that powers the Dashboard's time-invested figures.

Highlights:
- Unlimited-depth subtasks on Tasks/Recurring Tasks via a hidden hierarchy
  engine (parent/child keys, live renumbering, collapse/expand).
- Auto-archiving: completing a task snapshots it to Archive as static
  values, freezing any live/time-based fields at that moment.
- A live Dashboard with KPI cards, upcoming-deadline lists, and charts, all
  formula-driven from the other sheets.
- Popup forms (VBA UserForms) for notes, exchange rates, date/time pickers,
  and reminders.
- A single cross-cutting visual design system (validated, accessible color
  palette; consistent typography, iconography, and layout) rather than each
  sheet inventing its own look.

## Using the workbook

The finished file is **`Performance Marketing Dashboard.xlsm`** — open it in
Excel 2016/2019/365 and go. Macros must be enabled for the interactive
buttons and popups to work (Excel will prompt on first open).

Start on the **Instructions** sheet inside the workbook — it walks through
how each sheet is meant to be used.

## Rebuilding it from source

The workbook is entirely generated by Python, not built by hand:

```
pip install -r requirements.txt
python build_dashboard.py   # builds structure/formulas/formatting -> .xlsx
python inject_vba.py        # injects VBA via COM automation -> .xlsm
```

`inject_vba.py` drives a real, locally installed copy of Excel over COM
(`pywin32`), so it only runs on Windows with Excel installed, and requires
"Trust access to the VBA project object model" enabled once in Excel's
Trust Center on the machine doing the build.

## Project layout

```
build_dashboard.py   orchestrator — runs every sheet's build() in dependency order
inject_vba.py         injects vba/*.bas into the built workbook via COM
sheets/               one Python module per sheet (openpyxl)
sheets/design_system.py   the single shared color/typography/icon system
sheets/forms/          VBA UserForm builders (Notes, Exchange Rate, etc.)
vba/                   VBA source, one .bas per sheet/module
PLAN.md                the full design spec and decision log (source of truth)
```

`PLAN.md` documents every design decision — including a handful of
corrections made along the way, called out inline — and its final section is
a running debugging log for issues found after the workbook was in real use.
